# Security Policy

## Reporting a Vulnerability

Report security issues in this fork privately to security@hackerverse.ai.
Please do not open a public issue.

For vulnerabilities in the upstream project, report to the upstream
maintainers at https://github.com/pillar-labs/pocumentary.

## Scope

PocYeah executes the commands defined in a `demo.toml`. That is by design.
Running untrusted demo specs is out of scope; isolate anything you did not
author.
